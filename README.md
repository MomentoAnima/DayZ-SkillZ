# DayZ-SkillZ

A collection of reusable DayZ development skills for Claude.

## Creating a skill

Use the [skill authoring guide](.claude/skills/dayz-skill-authoring/SKILL.md) when
turning recurring work into a skill. Base guidance on repeatable patterns
supported by repository code, documentation, tests, or user-approved summaries.
Do not treat private conversation history as source material unless the user
explicitly provides it for this purpose.

Before sharing a skill, check the full text for:

- Server-specific details such as hostnames, addresses, ports, internal paths,
  private APIs, or deployment settings.
- Personal information such as names, usernames, contact details, or player
  identifiers.
- Secrets such as passwords, tokens, private keys, cookies, or credentials.

Remove sensitive details rather than masking them with realistic-looking
examples. Use clearly generic placeholders only when needed to teach a reusable
pattern, and have a person review the final skill before sharing it.
